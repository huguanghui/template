# SVG 绘图规范（精简自检版）

> 权威规范见项目根 `svg-style.md`。本文件仅列出生成+自检必需项。

## 根标签

```html
<svg viewBox="0 0 W H" xmlns="http://www.w3.org/2000/svg"
     font-family="system-ui, 'Noto Sans SC', sans-serif" font-size="15">
```

- 直接输出 `<svg>`，**不要包在 Markdown 代码块里**，否则不渲染。
- `W=1000~1200`，`H` 给足；宁可加高也不挤压文字。
- 中文用无衬线字体栈，避免 monospace。

## 字号层级

| 用途 | 字号/字重 |
| --- | --- |
| 分组标题 | 17-18 / 700 |
| 节点标题 | 15-16 / 600 |
| 正文 | 14-15 |
| 次级 | 13 |
| 注释 | 12-13，灰 `#6b7280` |

居中用 `text-anchor="middle"`，基线 `y ≈ 框中心 + 5`。

## 配色（填充 / 描边 / 主文字）

| 语义 | 填充 | 描边 | 主文字 |
| --- | --- | --- | --- |
| 蓝 · 进程/数据/处理 | `#dbeafe` | `#2563eb` | `#1e3a8a` |
| 绿 · 开始/成功/输入 | `#dcfce7` | `#16a34a` | `#14532d` |
| 琥珀 · 判断/分支 | `#fef3c7` | `#d97706` | `#78350f` |
| 红 · 错误/终止/关键 | `#fee2e2` | `#dc2626` | `#7f1d1d` |
| 紫 · 存储/索引 | `#ede9fe` | `#7c3aed` | `#4c1d95` |
| 青 · 缓冲/共享内存 | `#ccfbf1` | `#0d9488` | `#115e59` |
| 灰 · 中性/外部 | `#f3f4f6` | `#4b5563` | `#1f2937` |
| 分组框底色 | `#eff6ff` / `#f0fdfa` / `#fff7ed` | 对应描边 | — |

节点 `rx=8`、描边 1.5-2；分组大框 `rx=12`、`stroke-width=2`；起止可用胶囊 `rx=高/2`。一张图 ≤5 种色系。

## 箭头

- 主流程：`#374151` 宽 2 + `<defs><marker>`；分支标注「是/否」13/600。
- 异步/回环：`#9ca3af` 宽 1.8-2 + `stroke-dasharray="6 4"`。
- **同页多图 marker id 必须唯一**，按图加前缀：`f1ar`、`f2red`、`f3gray`…

```html
<marker id="f1ar" markerWidth="11" markerHeight="11" refX="8" refY="3.5" orient="auto">
  <path d="M0,0 L8,3.5 L0,7 Z" fill="#374151"/>
</marker>
```

## 文本转义

- `&` 写成 `&amp;`，`>` 写成 `&gt;`，`<` 写成 `&lt;`，不出现裸符号。
- 长标签拆成多个 `<text>`，不要溢出框。
- 符号可直接用：`→ ≥ ≤ · × ①②③`。

## 图型速查

| 图型 | 手法 |
| --- | --- |
| 架构 / 数据流 | 分层分组框 + 层内等宽节点 + 汇聚箭头 |
| 业务流程 | 中轴竖排 + 琥珀菱形判断 + 左右分支 + 下合流 |
| 调用 / 目录树 | 父上子下 + 缩进浅底框 |
| 字节布局 | 横排等宽区段 + 大字段名 + 小偏移注 |
| 管道 + 回环 | 横排节点 + 底部虚线回环 + 条件标注 |

## 自检

- [ ] XML 合法、标签闭合、无 id 重复。
- [ ] 文字不超出 `viewBox`。
- [ ] SVG 未处于代码块内。
- [ ] 运行 `scripts/validate_svgs.py <file.md>` 通过。
