## 2.1.195

这是对 Claude Code **v2.1.195** 最新版本的更新记录分析。本次更新侧重于**语音功能的本地化适配、后台任务的稳定性修复、以及针对复杂插件标识符的逻辑修正**。

以下是详细的分类整理：

### 1. 语音与听写功能改进 (对中文用户尤为重要)

- **修复无空格语言的自动提交**：修复了在**中文、日语、泰语**等不使用空格分隔单词的语言中，语音听写“自动提交”功能失效的问题。
- **macOS 设备切换修复**：修复了在长时间会话中，如果 macOS 默认输入设备发生更改，语音听写会录入静音的问题。
- **Linux 错误诊断优化**：在 Linux 上能更准确地区分是“未安装 SoX 软件”还是“安装了 SoX 但找不到麦克风硬件”。

### 2. 后台任务与 Agent 稳定性

- **跨版本数据兼容**：修复了当后台作业由更新版本的 Claude Code 写入时，在当前版本中消失或丢失数据的问题。
- **崩溃重启优化**：修复了重启已崩溃的后台任务时会黑屏 5 秒的问题，现在会立即显示重启状态。
- **守护进程逻辑修复**：修复了当控制套接字（Socket）启动失败时，后台 Agent 守护进程进入不可达状态并阻止重启的问题。

### 3. 插件与匹配逻辑优化

- **精确标识符匹配**：修复了带有连字符的标识符（如 `code-reviewer`, `mcp__brave-search`）会被错误地进行子字符串匹配的问题。现在改为**精确匹配**。
  - _提示_：若需匹配某个 MCP 服务下的所有工具，请使用正则格式，如 `mcp__brave-search__.*`。
- **插件权限安全**：修复了通过项目级 `.claude/settings.json` 启用的外部插件在不同加载路径下未要求明确安装许可的安全漏洞。
- **插件管理修复**：修复了当插件的 `plugin.json` 名称与市场（Marketplace）名称不一致时，`/plugin Enable/Disable` 命令失效的问题。

### 4. 交互与 UI 体验

- **新增鼠标点击开关**：新增环境变量 `CLAUDE_CODE_DISABLE_MOUSE_CLICKS`。开启后，在全屏模式下将禁用鼠标点击、拖拽和悬停功能，但保留鼠标滚轮滚动。这对于习惯纯键盘操作或防止误触的用户非常有用。
- **远程会话启动体验**：在远程会话启动容器期间，新增了“配置清单（Provisioning Checklist）”显示，让等待过程更透明。
- **Agent 列表布局优化**：改进了 Agent 完成列表的垂直空间利用。在高度较小的终端窗口中，标题栏会自动收缩，以确保当前活跃会话保持可见。

---

### 总结分析

**v2.1.195** 是一个关键的修复补丁版本，特别解决了**中文语音用户**在使用听写功能时的痛点。同时，它增强了后台任务在崩溃、升级以及复杂网络套接字失效情况下的鲁棒性。

**建议操作：**

1. **中文语音用户**：建议立即更新以获得正常的自动提交体验。
2. **插件开发者/重度用户**：如果你的插件或 MCP 服务名称带有连字符（-），请注意匹配逻辑的变化，必要时更新你的正则匹配规则。

## 2.1.193

这是对 Claude Code **v2.1.193** 版本更新记录的详细分析与整理。本次更新主要集中在**自动化模式的安全与交互、后台任务（Backgrounding）的稳定性、MCP（Model Context Protocol）体验优化**以及**性能监控**四个方面。

以下是分类整理的内容：

### 1. 核心新特性与功能增强

- **Bash 模式实时路径补全**：在 Bash 模式下支持文件路径的实时自动补全，显著提升了命令行操作效率。
- **全量 Shell 命令安全过滤**：新增 `autoMode.classifyAllShell` 设置。开启后，所有的 Bash/PowerShell 命令都会经过自动模式分类器，而不仅限于匹配到“任意代码执行”模式的命令。
- **权限拒绝原因透明化**：在会话历史、拒绝弹窗（Toast）以及 `/permissions` 最近拒绝记录中，现在会显示具体的“自动模式拒绝原因”，让用户清楚为何某些操作被拦截。

### 2. 后台任务与 Agent 逻辑优化 (关键改进)

- **消除后台任务干扰**：改进了后台 Agent 的指令逻辑。启动后台 Agent 后不再强制要求 Claude “结束当前响应”，使其能够继续处理其他任务，实现更高效的并行工作。
- **修复后台切换 Bug**：
  - 修复了使用 `←←` 快捷键切入后台时，错误提示“将放弃 N 个后台任务”的问题（实际这些任务会带入新会话）。
  - 修复了主对话切入后台时，会产生一个幻影“通用（恢复）”子 Agent 并重复执行主对话的问题。
- **Agent 面板显示修复**：修复了在查看子 Agent 时，Agent 面板会隐藏同级（Sibling）Agent 的 UI 问题。
- **固定 Agent 状态保持**：修复了在自动更新后，被固定的后台 Agent 每次都会弹出“从上次中断的地方继续”提示的问题。

### 3. MCP 与 插件系统改进

- **MCP 身份验证提醒**：启动时如果 MCP 服务器需要身份验证，会发出通知并引导用户前往 `/mcp` 进行配置。
- **MCP 自动重连**：改进了 `headersHelper` 鉴权。当工具调用返回 401（未授权）或 403（禁止访问）错误时，助手会自动重新运行鉴权并尝试重新连接。
- **插件自动更名**：支持自动跟随市场（Marketplace）的重命名映射，自动更新配置文件中的插件名称。

### 4. 性能与系统维护

- **内存压力自动释放**：新增后台 Shell 命令的自动“收割”机制（Memory-pressure reaping）。当系统内存紧张时，会自动清理闲置的后台 Shell 进程（可用 `CLAUDE_CODE_DISABLE_BG_SHELL_PRESSURE_REAP=1` 禁用）。
- **遥测日志增强**：新增 `claude_code.assistant_response` 日志事件，用于记录模型响应文本。
  - _注意_：默认脱敏。需设置 `OTEL_LOG_ASSISTANT_RESPONSES=1` 开启记录。如果未设置该变量，它将跟随 `OTEL_LOG_USER_PROMPTS` 的配置。

### 5. 其他 UI/UX 修复

- **登录状态同步**：修复了执行 `/login` 后，`/model` 等依赖客户端数据的 UI 界面仍显示旧状态或空状态的问题。
- **提示语优化**：改进了 `/add-dir` 的反馈消息，当添加的目录已经是工作目录时，提示更准确。

---

### 总结分析

本次更新是一个**稳定性和易用性**的大版本迭代。

- **对于开发者**：路径补全和更智能的后台 Agent 让 Claude Code 作为一个开发终端工具更加成熟。
- **对于企业/安全关注者**：全量 Shell 命令过滤和更详细的权限拒绝记录提升了安全可控性。
- **对于性能关注者**：内存自动清理机制解决了长时间运行可能导致的资源占用问题。

以下是对 v2.1.157 版本更新内容的结构化翻译 + 分类整理：

一、主要新功能（New Features）

本地 Skills 插件自动加载（重要更新）
位于 .claude/skills 目录下的插件现在自动加载，无需通过插件市场安装。

插件初始化命令
新增 claude plugin init <name> 命令，可快速在 .claude/skills 目录下创建新插件脚手架。

插件命令自动补全
/plugin 命令的参数现在支持自动补全（子命令、已安装插件、市场插件）。

Agents 配置增强
settings.json 中的 agent 字段现在对 dispatched sessions 生效。
可使用 --agent <name> 参数进行覆盖。

工作树切换能力
EnterWorktree 现在支持会话中途切换 Claude 管理的工作树。

遥测增强
tool_decision 遥测事件在开启 OTEL_LOG_TOOL_DETAILS=1 时，会包含工具参数（bash 命令、MCP/技能名称）。

二、体验与功能优化（Improvements）

Claude 管理的工作树在 Agent 完成后保持解锁状态，方便使用 git worktree remove/prune 清理。
显著提升长会话和恢复会话的性能（减少重复渲染计算）。
/terminal-setup 现在默认在 VS Code / Cursor / Windsurf 集成终端中禁用 GPU 加速，防止文字渲染错乱。
“Feature of the Week” 领取状态移至状态栏显示。
claude agents 中斜杠命令自动补全支持子字符串匹配。
新增 /config 设置 “Workflow keyword trigger”，可关闭单词 “workflow” 自动触发动态工作流。
移除部分启动提示（如沙箱提示、IDE 提示），减少干扰。
按 Backspace 取消 Workflow 触发请求（与 Alt+W 相同）。

三、Bug 修复（Bug Fixes）
本次修复内容较多，重点覆盖了后台 Agent、工作树、WSL、终端渲染等方面：

修复粘贴损坏/零字节图片导致请求崩溃的问题。
修复 Auto 模式和 Bypass-Permissions 模式下仍弹出沙箱网络权限提示的问题。
修复后台 Agent 完成会话后未正确退休的问题。
修复 Esc 键无法取消 “opening…” 状态导致列表卡死的问题。
修复后台工作树在 30 天清理后成为孤儿的问题。
修复从睡眠唤醒后会话日期错误的问题。
修复 tmux 中 copy-on-select 无法复制到系统剪贴板的问题。
修复 --resume 无法显示后台子 Agent 的问题。
修复 WSL 下图片粘贴、截图粘贴支持问题，并新增从 Windows 资源管理器拖拽图片支持。
修复多个终端渲染、快捷键、剪贴板相关 Bug。
修复 VS Code 中 Stop 按钮无法停止后台子 Agent 的问题。
修复 Opus 4.8 的 Fast Mode 指示器不显示的问题。

版本总结
v2.1.157 是一个以开发者体验和易用性为主的版本。
核心亮点：

本地插件系统大幅简化：现在可以直接在 .claude/skills 目录开发和使用插件，无需市场。
插件开发友好度提升（新增 plugin init + 自动补全）。
工作树管理和后台 Agent 稳定性继续加强。
性能和细节体验优化明显，尤其适合长期使用和大项目场景。

建议：
如果你经常开发自定义 Skills/插件，或者大量使用 Agents 和 Worktree，这个版本值得更新。

## 2.1.154

Claude Opus 4.8 正式发布（最大亮点）
Opus 4.8 已上线，默认使用 High Effort（高智能模式）。
新增 /effort xhigh 指令，可用于最难、最复杂的任务。

动态工作流（Dynamic Workflows） —— 重磅功能
你可以直接让 Claude 创建一个 Workflow，它会在后台自动编排数十到数百个 Agent 协同工作。
适合处理大型、复杂任务。

Opus 4.8 Fast Mode 价格大幅降低

除 Haiku、Sonnet、Opus 4.7 及更早版本外，所有模型默认使用精简系统提示（提升效率）。

在 claude agents 中输入 ! <命令>，即可作为一个可随时附着/分离的后台会话执行 Shell 命令。

/effort 滑块标签从 “Speed/Intelligence” 改为 “Faster/Smarter”，更清晰。
←← 快捷键打开 Agents 视图，现在在 Bedrock、Vertex、Foundry 以及关闭遥测时均可使用。
Chrome 浏览器集成：支持通过 /chrome → Select browser… 选择要使用的浏览器。
Streaming Tool 执行现在默认始终开启（不再受功能旗标限制）。
/model 选择器在 Fast Mode 开启时会显示对应价格。
改进自动模式的安全分类器，特别加强了对大批量代码库内容外泄的检测。

三、Bug 修复（Bug Fixes）
本次修复重点集中在后台工作流、权限控制、安全性和稳定性：

修复 rm -rf $HOME 在 HOME 路径带斜杠时未被正确拦截的问题。
修复 $TMPDIR 在沙箱与非沙箱命令中解析不一致的问题。
修复大量后台 Agent（Background Agent）相关问题（固定、卡住、重复启动、CPU 100% 等）。
修复 Subagent 绕过工作树隔离保护的问题。
修复 Windows 更新失败时的提示不清晰问题。
修复 VS Code 扩展关闭时进程未正确清理的问题。
修复 /mcp 工具列表在工具名过长时的渲染问题。
修复自动模式在安全分类器 Token 用尽时错误阻挡操作的问题。
其他终端渲染、快捷键、链接点击、计划文件命名等细节修复。

版本总结
v2.1.154 是一个重量级功能更新版本，核心亮点如下：

Opus 4.8 正式到来 + Dynamic Workflows（动态工作流）是本次最大升级，极大提升了处理复杂大型任务的能力。

Agents 后台执行能力进一步增强（! 命令非常实用）。
整体稳定性和安全性继续打磨。
