# deepseek-harness

## 安装

```bash
npm install -g @deepseek-ai/dsh
dsh --version   # 验证
dsh web         # 启动 Web UI
```

## 使用

### 1. 先查看当前版本

dsh --version

### 2. 查看 npm 上最新版本

npm view @deepseek-ai/dsh version

### 或查看所有通道（latest / next 等）

npm view @deepseek-ai/dsh dist-tags

### 3. 更新到 latest

npm update -g @deepseek-ai/dsh

### 或者更强制地重新安装最新版（推荐）

npm install -g @deepseek-ai/dsh@latest
