**Linux C 嵌入式开发中使用 ClaudeCode 的推荐技能**（高效提效指南）

ClaudeCode 在嵌入式 Linux C 开发中非常强大，尤其适合 **ARM、RK、IMX、AX系列** 等平台。下面是**最推荐的技能用法**：

---

### 1. **核心优势场景**（ClaudeCode 特别擅长）

- 驱动开发（字符设备、platform driver）
- 内核模块编写
- 交叉编译环境配置
- 设备树（DTS）编写与调试
- 性能优化与内存管理
- 实时性问题排查（PREEMPT_RT 等）

---

### 2. **推荐 Prompt 模板**（直接复制使用）

#### **1. 驱动开发**

```prompt
你在Linux嵌入式C开发专家，平台是ARM64，使用最新内核。
请帮我写一个 [设备类型] 的字符设备驱动，要求：
- 支持 open/read/write/ioctl
- 使用 platform_driver 框架
- 包含设备树匹配
- 添加完整错误处理和日志
- 符合内核编码规范
```

#### **2. 调试问题**

```prompt
我遇到以下嵌入式Linux问题：
[粘贴报错信息或现象]
平台：ARM + Linux 5.x
请分析可能原因，并给出排查步骤和修复方案。
```

#### **3. 内存/性能优化**

```prompt
这是一个嵌入式Linux C代码，运行在资源受限设备上：
[代码]
请帮我优化内存占用和执行效率，重点关注：
- 减少malloc/free
- 使用静态内存
- 避免不必要的拷贝
```

---

### 3. **高效使用技巧**

**推荐技能组合**：

1. **先让 ClaudeCode 理解你的环境**
   - 第一次对话时告诉它：
     - 芯片平台（e.g. RK3588 / AX620A）
     - 内核版本
     - 交叉编译工具链
     - 具体需求（驱动 / 应用 / 内核模块）

2. **分步开发法**（最推荐）
   - 先让它生成框架
   - 再逐步完善功能
   - 最后优化和加注释

3. **代码审查能力**
   - 把你的代码扔给它，让它找出潜在 Bug（尤其是内存泄漏、空指针、竞态）

---

